# Дневник Суи ♡

Милый личный дневник-планировщик (PWA). Всё хранится только в твоём телефоне, без регистрации и серверов.

## Что внутри папки
- `index.html` — главный экран
- `styles.css` — дизайн, 4 темы. ВНИМАНИЕ: файл должен называться ровно `styles.css`, без `.txt` на конце!
- `app.js` — логика: неделя Пн–Вс, день, фото, напоминания
- `sw.js` — чтобы работало без интернета
- `manifest.webmanifest` + `icon.svg` — иконка и установка на iPhone
- `girls/` — твои девочки: `nastya.png`, `alisa.png`, `nyusha.png`, `ksyusha.png` (+ `-1.png`, `-2.png`… для чередования по тапу). Нет файлов — покажутся встроенные рисунки ♡ ВАЖНО: имена должны быть ровно такие, без двойного `.png.png` (включи «Расширения имён файлов» в Проводнике, чтобы видеть настоящее имя). Чужие картинки из интернета не выкладывай на GitHub — только у себя!

## Как посмотреть на компьютере (очень просто)
1. Открой папку `дневник`.
2. Дважды кликни по `index.html` — откроется в браузере.
3. Если стили не применились (белый экран): проверь, что файл называется `styles.css`, а не `styles.css.txt`.
   Как проверить: в Проводнике сверху нажми «Вид» → поставь галочку «Расширения имён файлов». Тогда видно настоящее название.

## Как залить на GitHub Pages (по шагам)
1. Зайди на github.com, создай бесплатно аккаунт.
2. Нажми `New repository`, назови например `sui-diary`, поставь Public, нажми Create.
3. Нажми `uploading an existing file` (загрузить файлы) и перетащи ВСЕ файлы из папки `дневник` (index.html, styles.css, app.js, sw.js, manifest.webmanifest, icon.svg, icon-192.png, icon-512.png, apple-touch-icon.png, preview-girls.html). Папку `girls/` с чужими картинками НЕ загружай!
4. Нажми Commit.
5. Зайди в `Settings` → `Pages` → в `Branch` выбери `main` и папку `/ (root)`, нажми Save.
6. Через минуту появится ссылка вида `https://твоё-имя.github.io/sui-diary/` — это твой дневник в интернете ♡

## Как поставить на iPhone
1. Открой свою ссылку в Safari (именно Safari!).
2. Нажми кнопку «Поделиться» (квадратик со стрелкой вверх).
3. Выбери «На экран “Домой”» → «Добавить». Появится розовая иконка «Дневник Суи» 🎀
4. Открывай как обычное приложение. Дальше интернет не нужен!

## Напоминания
Айфон не разрешает будить закрытое приложение без сервера, поэтому:
- пока дневник открыт — будет перезвон + вибрация + уведомление;
- если пропустила — при следующем входе покажу розовый тост «Пропущенное ⏰».
В настройках (⚙️) нажми «Разрешить уведомления» и «Проверить звук» ♪

## Важно про фото
Фото сжимаются до 900px, чтобы поместиться в память телефона (~5 МБ). Очень старые записи с большими фото лучше удалять.
